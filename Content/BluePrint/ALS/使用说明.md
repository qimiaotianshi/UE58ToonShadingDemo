# DreamBloom 74–76 合并更新包（插件1.46）

只需安装这一份，不需要再依次覆盖74、75、76。包内已按74 → 75 → 76合并，提供完整插件与Content/BluePrint/ALS资源。

包含BaseAnim/BaseAnim3的走跑、真实起步/收步、脚步同步与移动曲线、空格跳跃/下落/落地、随机待机；已删除待机跟随镜头自动转身；四份起跳动画已修复整体升空位移叠加。脚底IK、KawaiiPhysics世界平移抑制、滚轮缩放、地图加载界面、展示交互与暂停返回保留。
原74有20份重做动作，删除两份转身后当前使用18份；历史动作资源保留以兼容已有引用。原模型与骨架沿用74完整包。

## 推荐安装：一次完成覆盖、备份和旧文件清理

1. 解压压缩包。把目标工程保存并关闭UE和正在运行的游戏。
2. 在解压目录打开PowerShell，用目标工程根目录运行安装脚本。根目录必须包含你的.uproject。

官方UE5.8引擎：

```powershell
powershell -ExecutionPolicy Bypass -File .\InstallUpdate.ps1 -ProjectRoot "D:\你的工程"
```

自己修改过源码的引擎：

```powershell
powershell -ExecutionPolicy Bypass -File .\InstallUpdate.ps1 -ProjectRoot "D:\你的工程" -SourceEngine
```

源码引擎用法会跳过本包官方DLL，移开目标旧Binaries/Intermediate；随后在Rider中用目标工程Editor / Development配置Build一次，再打开UE。根据目标工程情况重新生成项目文件。

脚本把所有被覆盖的旧文件及旧插件Source/Binaries/Intermediate保存到目标工程Saved/DreamBloomUpdateBackups/Combined74_76-时间戳。它替换整个插件Source以避免旧文件或Source/Source残留；只覆盖本包提供的ALS文件，其他工程目录不参与更新。
脚本也会删除6个旧转身uasset/FBX并备份。直接复制覆盖文件夹不会删除旧文件，因此推荐使用脚本。
不要把解压目录当成目标工程。此脚本针对已有项目，是文件安装工具，不会自动设置引擎、插件开关、打包或菜单目的地。

## 手工覆盖

保存并关闭UE，备份目标Plugins/DreamBloom及Content/BluePrint/ALS。将本包的Plugins/DreamBloom和Content/BluePrint/ALS复制到工程同名位置，完整替换插件Source，避免嵌套Source/Source。
删除Animations/A_ALS_Turn_L.uasset、A_ALS_Turn_R.uasset，以及SourceAssets/Locomotion73、Locomotion74中的A_ALS_Turn_L.fbx、A_ALS_Turn_R.fbx。自改源码引擎移开Binaries/Intermediate后重编。

## 当前默认配置

DA_ALSLocomotion已经配置好，不用逐项填写新动作；安装后BP_ALSCharacter使用这份DA与ABP_ALSLocomotion。包内DA会覆盖目标同名DA；若你在旧DA定制过速度、动作、镜头或输入，请从备份核对并重新设置。
你自己的展示角色DA、DA_WardrobeMenu和其他工程内容不包含在本包内。

|操作|按键|
|---|---|
|走路|WASD|
|跑步|Shift + WASD|
|跳跃|Space|
|转镜头|鼠标移动，待机人物不随镜头转身|
|镜头缩放|鼠标滚轮|
|暂停/返回展示|Esc|

起步、收步、走跑过渡、下落和落地自动触发。DA的Input已引用IMC_ALS和IA_Move、IA_Look、IA_Sprint、IA_Jump、IA_Zoom、IA_Pause。
Walk/Run Speed=160/420cm/s；Walk/Run Animation Speed≈95.195/399.113cm/s；Blend Time=0.2s。
Jump Velocity=420cm/s，默认重力下胶囊上升约90cm。若想更低，350约63cm，300约46cm。不要再使用旧74未修复的四份同名起跳动画。
Walk Start Left/Right均用A_ALS_WalkStart；Run Start两项均用A_ALS_RunStart；停止和跳跃仍各有左右版本。Air/Fall/轻重落地和IdleGesture均已配置。
